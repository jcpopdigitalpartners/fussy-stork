# 3.1 — What survives a replacement?

What state disappears with a Pod—and what should survive?

## Investigate

1. Before removing anything, identify which values come from the image, environment, process memory, and persistent storage.
2. Test one claim in your local environment. Capture the command, result, and any failure.
3. Compare the observation with the evidence target. Explain what remains unproven.

## Evidence target

Replacement restores code and configuration, but not arbitrary writes in a disposable container layer.

## Check your work

Capture an `api` vet report before a fault, then rerun with `--baseline` after recovery. Complete the recovery evidence rubric.

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Separate memory, writable layers, ephemeral volumes, and PersistentVolumeClaims. Compare where the record was stored.
