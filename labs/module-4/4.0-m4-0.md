# 4.0 — Working ≠ safe

Which observed property would most change your first hardening decision, and why?

## Investigate

1. Record the health response and identify exactly what that probe exercises.
2. Inspect the effective process identity, groups, and writable mounts or paths.
3. Capture the image reference and observed configuration in a baseline note.

## Evidence target

A baseline note that ties the health response, runtime identity, and writable surfaces to a named workload and image.

## Check your work

Use the `security` vet check for a running Podman container. Admission, scan, SBOM and trust claims need the separate artifact/evidence rubric.

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Preserve the exact error, inspect the workload and its events, then change one variable at a time.
