# 4.1 — Run without root

What failed as a result of reduced privilege, and what behavior must still succeed?

## Investigate

1. Inspect the effective UID and group before you make a change.
2. Adapt the image or runtime configuration to use a non-root process; retest identity.
3. Attempt an explicitly protected write and repeat the API health check.

## Evidence target

Before/after identity evidence, the rejected protected write, and a succeeding application request.

## Check your work

Use the `security` vet check for a running Podman container. Admission, scan, SBOM and trust claims need the separate artifact/evidence rubric.

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Preserve the exact error, inspect the workload and its events, then change one variable at a time.
