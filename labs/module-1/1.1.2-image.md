# 1.1.2 — Build an OCI image

Which settings survive image reuse?

## Investigate

1. Write api/Containerfile and api/.containerignore; explain the role of each instruction.
2. Build and inspect your OCI image, then run it and compare the health and readiness responses.
3. Run the image vet check using the running container and the expected image reference. Commit the recipe and evidence.

## Evidence target

A call to /health succeeds through the published container port.

## Check your work

Use `process`, `image`, or `api` vet checks at the appropriate stage. See [solution checks](../../docs/vetting.md).

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Inspect the port mapping and which interface the application binds inside the container.
