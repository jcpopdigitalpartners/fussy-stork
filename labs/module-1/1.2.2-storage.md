# 1.2.2 — Preserve application data

What survives deleting an API container?

## Investigate

1. Create a record, replace the API container, and look for the same record. Compare data storage with compute lifecycle.
2. Test one claim in your local environment. Capture the command, result, and any failure.
3. Compare the observation with the evidence target. Explain what remains unproven.

## Evidence target

Records survive database-container replacement when the same persistent volume is reused.

## Check your work

Use `process`, `image`, or `api` vet checks at the appropriate stage. See [solution checks](../../docs/vetting.md).

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

A volume preserves data across container replacement; it does not guarantee a recoverable backup.
