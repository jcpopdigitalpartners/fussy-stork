# 1.2.1 — Connect the services

What does the database hostname resolve to?

## Investigate

1. Connect the API and database as separate services and derive the API’s database address from the actual network.
2. Use the api vet check to verify readiness and a real record round trip. Inspect the service/network membership independently.
3. Save the run settings, network inspection and vet report. Commit the configuration and your explanation.

## Evidence target

Create a record through the API, then retrieve it from PostgreSQL.

## Check your work

Use `process`, `image`, or `api` vet checks at the appropriate stage. See [solution checks](../../docs/vetting.md).

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Inside a container, localhost points to that container. Check the network name and database service hostname.
