# 0.2 — Establish your toolchain baseline

Does the cloned workspace have a working toolchain?

## Investigate

1. Use the OS guide to install the six preparation tools inside the Linux environment that contains your student clone. Leave Kubernetes for Module 2.
2. From ~/containers-practice-starter, run bash scripts/preflight.sh --runtime and save the report to evidence/module-0/preflight.txt.
3. Explain what the version checks and hello container prove. Resolve failures before using the result as the Checkpoint 0 baseline.

## Evidence target

All six preparation tools respond, the hello container executes successfully, and evidence/module-0/preflight.txt records the actual result.

## Check your work

Run `bash scripts/preflight.sh --runtime` and save evidence/module-0/preflight.txt. Node.js is not needed for this check.

## If the result differs

Choose your operating system in the installation guide. Check the package manager response and confirm you are in the named terminal. RHEL may require enabled repositories.
