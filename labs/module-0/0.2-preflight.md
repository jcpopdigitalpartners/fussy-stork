# 0.2 — Verify your environment

Does the runtime execute an image?

## Investigate

1. Run the six version checks and the Podman hello image. Explain which result proves that a container actually executes.
2. Clone this repository inside your Linux environment. Inspect its starter commit and choose a task branch.
3. Confirm README.md, api/ and evidence/ are present. Save the runtime result for Checkpoint 0.

## Evidence target

The hello container succeeds, your cloned learner workspace is available inside Linux, and its starter commit is visible.

## Check your work

Run `bash scripts/preflight.sh --runtime`. Node.js is not needed for this preparation check.

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Separate registry/network failures from rootless runtime failures; preserve the error before reinstalling anything.
