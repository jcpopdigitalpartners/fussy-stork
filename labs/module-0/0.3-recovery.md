# 0.3 — Recover deliberately

What failed before you changed anything?

## Investigate

1. Write the first failing command, exact error, and last known-good output before attempting a repair.
2. Test one claim in your local environment. Capture the command, result, and any failure.
3. Compare the observation with the evidence target. Explain what remains unproven.

## Evidence target

You can explain what broke and identify the last known-good state.

## Check your work

Run `bash scripts/preflight.sh --runtime`. Node.js is not needed for this preparation check.

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Compare only one variable at a time. Reset after you have captured enough evidence to explain the failure.
