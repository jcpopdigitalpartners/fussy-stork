# 0.5 — Checkpoint 0 & next steps

Is your environment ready for someone else to reproduce it?

## Investigate

1. Record the six tool versions, guest resource checks and successful hello-container result in evidence/baseline.md.
2. Review and commit that evidence, then create a local checkpoint-0 tag on your own work.
3. Inspect the checkpoint and distinguish what belongs inside an application image from what stays outside it.

## Evidence target

Record your result, establish Checkpoint 0 in source control, and begin the reproducibility exercise from a verified environment.

## Check your work

Run `bash scripts/preflight.sh --runtime`. Node.js is not needed for this preparation check.

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

Verify an OCI container actually runs—not just that a version command responds. Then use the next-module handoff below to preview what becomes reproducible.
