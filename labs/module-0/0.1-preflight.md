# 0.1 — Clone your student workspace

Are you working in the student repository?

## Investigate

1. Use the setup guide to prepare Linux and Git. Clone https://github.com/jcpopdigitalpartners/fussy-stork.git into ~/containers-practice-starter inside Linux.
2. Inspect origin and the supplied history. Confirm README.md, api/, labs/, scripts/, work/ and evidence/ exist; the student repository is fussy-stork.
3. Set your local Git identity and inspect the clean starting state. Continue to 0.2 to install and verify the remaining course tools.

## Evidence target

The student repository is cloned inside Linux, origin identifies fussy-stork, and the supplied history and lab files are visible.

## Check your work

Inspect the clone remote, supplied history and clean starting state. Run the runtime preflight in 0.2 after installing its tools.

## If the result differs

A .git suffix belongs to the clone URL, not a separate shell command. If cloning completes, inspect the remote before retrying. Preserve an existing workspace rather than overwriting it.
