# 0.0 — A testable baseline

Can your computer support the labs before you install anything?

## Investigate

1. Use the workstation sizing table and resource check in Opening, Module −0.1. Record logical CPU count, RAM, free storage and virtualization support; compare host and Linux guest allocations if applicable.
2. Test one claim in your local environment. Capture the command, result, and any failure.
3. Compare the observation with the evidence target. Explain what remains unproven.

## Evidence target

You can run the tools, execute a container, and return to a known checkpoint.

## Check your work

Run `bash scripts/preflight.sh --runtime`. Node.js is not needed for this preparation check.

A passing automated check covers the named observations only. Use [the evidence rubric](../../docs/evidence-rubric.md) for the rest of this lesson’s claim.

## If the result differs

WSL and Lima are resource-limited virtual environments. Check guest allocation independently of host capacity, and reduce workloads or reserve more resources before scaling labs.
